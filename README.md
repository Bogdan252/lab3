# Лабораторная работа №3 (РБПО)

## Стек технологий:
- Java 21
- Spring Boot 3.3.4 (Spring Data JPA, Spring Web)
- MySQL 8.3.0
- Lombok, Spring Dotenv

## Описание проекта:
Проект представляет собой бэкенд-приложение для автоматизации закупок (управление пользователями, поставщиками, заявками, коммерческими предложениями и заказами).
